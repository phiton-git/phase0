# Data Dictionary

Seluruh data adalah sintetis untuk latihan.

| Kolom | Tipe | Definisi |
|---|---|---|
| id | integer | ID listing sintetis |
| name | string | Nama listing sintetis |
| neighbourhood | string | Wilayah simulasi |
| room_type | string | Entire home/apt, Private room, Shared room |
| price | float | Harga per malam dalam USD simulasi |
| minimum_nights | integer | Minimal malam menginap |
| number_of_reviews | integer | Total review sintetis |
| reviews_per_month | float | Rata-rata review per bulan sintetis |
| availability_365 | integer | Hari tersedia dalam 365 hari simulasi |
| host_listings_count | integer | Jumlah listing host sintetis |

## Batasan
Dataset tidak merepresentasikan listing, transaksi, booking, review, atau harga aktual di Singapore maupun kota lain.
