# Accommodation Market Demand & Supply Analysis

## Project Overview
Project ini mempelajari bagaimana seorang Data Analyst menganalisis pasar penginapan dari sisi supply dan indikator aktivitas tamu. Tujuannya adalah membandingkan jumlah listing, aktivitas review, harga, lokasi, dan tipe penginapan.

## Problem Statement
Pemilik penginapan membutuhkan gambaran mengenai lokasi dan tipe properti yang menunjukkan indikasi aktivitas tamu relatif tinggi serta bagaimana kondisi penawaran dan harga di wilayah tersebut.

## Objectives
1. Mengukur jumlah listing sebagai gambaran supply.
2. Membandingkan aktivitas review total dan rata-rata per listing.
3. Mengeksplorasi hubungan harga dengan aktivitas review.
4. Merangkum karakteristik data menggunakan statistik deskriptif.
5. Menguji perbedaan distribusi aktivitas review antar-room type.

## Dataset
Dataset dalam paket ini adalah **data dummy/sintetis untuk pembelajaran**. Dataset ini tidak berasal dari Airbnb atau Inside Airbnb. Untuk submission MS1, ganti dengan dataset asli non-dummy, cantumkan URL sumber, dan konsultasikan kepada buddy.

Review hanya proxy aktivitas tamu dan bukan booking aktual. Availability bukan occupancy. Analisis ini merupakan latihan edukasi, bukan rekomendasi investasi.
